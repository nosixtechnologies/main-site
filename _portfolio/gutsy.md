GutsyHome provides Landlords, Property Managers and Realtors with a simple, hands-on tool to submit and manage everyday property repairs and maintenance. GutsyHome also facilitates one-click rent payment, document storage and an effective communications platform between Landlords, Property Managers, Tenants, and Vendors.

Key Features:

* Request Repair services with 3 easy clicks
* Pay repairs, maintenance, and rent with 2 easy clicks
* Ensure effectiveness and transparency: document and follow the status of each repair request, vendor visit, estimate and payment process
* Intuitive 3-way communication tool for Landlords, Property Managers, Tenants, and Vendors provides effective supervision over each repair request
* Store property documents and photos for easy reference by Tenant and Landlord
* Monitor on-time rent payment
* The landlord can select Preferred Vendors or allow for first-come, first-serve from Certified GutsyHome vendor pool
* Tenant and Landlord Rate Vendors
